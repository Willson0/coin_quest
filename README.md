## О проекте

**CoinQuest** — это образовательная платформа, которая помогает пользователям изучать основы работы криптовалюты в интерактивном формате.

Проект реализован в виде Telegram-бота с WebApp-интерфейсом и включает демонстрационный кошелёк, функции покупки и продажи криптовалюты, а также административную панель для управления системой.  
Авторизация выполняется через Telegram, что делает вход быстрым и удобным.

---

## Основной функционал

- Авторизация через Telegram
- Создание демо-кошелька
- Покупка криптовалюты
- Продажа криптовалюты
- Административная панель
- Образовательный сценарий для изучения криптовалют
- Telegram Bot + WebApp
- Адаптивный интерфейс

## Запуск проекта

Проект запускается с помощью Docker.

### Требования
- Docker
- Docker Compose

### Установка и запуск

```bash
docker-compose up --build
```


После запуска приложение будет доступно по адресу, указанному в конфигурации Docker.
